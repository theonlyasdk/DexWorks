# DexWorks

**DexWorks** is an Android app that lets you look inside other Android apps — right on your phone. No desktop computer needed.

It is built for developers, security researchers, QA testers, and anyone curious about what's inside an app.

## What it does

DexWorks is like a portable lab for Android packages. You can:

- Browse the apps installed on your device and APK files on your storage.
- See the inside of an app: its structure, manifest, components, permissions, signatures, certificates, resources, and native libraries.
- Extract APKs, splits, assets, resources, and other embedded files.
- Decompile DEX files into readable source code.
- Disassemble DEX files into Smali bytecode.
- Navigate and search through classes, methods, and code.
- Analyze apps that use multiple DEX files or package splits.

In short: it helps you understand what's inside an application, straight from your Android device.
